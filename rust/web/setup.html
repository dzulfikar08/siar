Claude.ai

No API key needed: Claude signs in to siar for you.

  1. In Claude, open Customize, then Connectors.
  2. Choose + Add, then Add custom connector.
  3. Name it siar and paste this URL, then choose Continue and keep the suggested sign-in settings:
{{mcp_url}}

Claude opens siar in a new tab. Sign in with GitHub or Google and choose Allow. In a chat, turn siar on from the + menu under Connectors.

On Team and Enterprise plans an owner adds the connector under Organization settings, Connectors; each member then connects it from Customize, Connectors. The connector also shows up in Claude Desktop and the mobile apps. To sign it out, revoke it under Connected apps in your siar dashboard.

ChatGPT

No API key needed: ChatGPT signs in to siar for you. Custom MCP servers need developer mode, which OpenAI offers on paid plans; on Plus and Pro, OpenAI may limit custom connectors to read-only tools.

  1. Turn on Developer mode in ChatGPT's settings (under Apps, Advanced settings; OpenAI moves it from time to time).
  2. Create an app or connector for an MCP server: name it siar, paste this URL and choose OAuth as the authentication:
{{mcp_url}}

ChatGPT opens siar to sign in; choose Allow. Then add siar to a chat from the + menu under developer mode.

Menu names follow OpenAI's help article "Developer mode and MCP apps in ChatGPT". From the terminal, Codex uses an API key instead: see the Codex tab.

Claude Code

Run this once in a terminal. Claude Code picks siar up in every new session.

claude mcp add --transport http siar {{mcp_url}} \
  --header "Authorization: Bearer {{key}}"

Claude Desktop

In Claude Desktop, open Settings, then Developer, then Edit Config, and add siar to claude_desktop_config.json. It runs through mcp-remote, so Node.js must be installed. Restart Claude Desktop afterwards.

{
  "mcpServers": {
    "siar": {
      "command": "npx",
      "args": ["-y", "mcp-remote", "{{mcp_url}}",
               "--header", "Authorization:${SIAR_AUTH}"],
      "env": { "SIAR_AUTH": "Bearer {{key}}" }
    }
  }
}

Simpler: add siar as a connector in Claude.ai (see the Claude.ai tab). Connectors you add there appear in Claude Desktop too, with no key in a config file.

Cursor

In ~/.cursor/mcp.json, or .cursor/mcp.json inside a project:

{
  "mcpServers": {
    "siar": {
      "url": "{{mcp_url}}",
      "headers": { "Authorization": "Bearer {{key}}" }
    }
  }
}

Codex

In ~/.codex/config.toml, with the key in an environment variable:

[mcp_servers.siar]
url = "{{mcp_url}}"
bearer_token_env_var = "SIAR_API_KEY"
export SIAR_API_KEY={{key}}

Windsurf

In ~/.codeium/windsurf/mcp_config.json:

{
  "mcpServers": {
    "siar": {
      "serverUrl": "{{mcp_url}}",
      "headers": { "Authorization": "Bearer {{key}}" }
    }
  }
}

Other MCP clients
