Claude Code

Run this once in a terminal. Claude Code picks siar up in every new session.

claude mcp add --transport http siar {{mcp_url}} \
  --header "Authorization: Bearer {{key}}"

Claude Desktop

In Claude Desktop, open Settings, then Developer, then Edit Config, and add siar to claude_desktop_config.json. It runs through mcp-remote, so Node.js must be installed. Restart Claude Desktop afterwards.

{
  "mcpServers": {
    "siar": {
      "command": "npx",
      "args": ["-y", "mcp-remote", "{{mcp_url}}",
               "--header", "Authorization:${SIAR_AUTH}"],
      "env": { "SIAR_AUTH": "Bearer {{key}}" }
    }
  }
}

Claude.ai in the browser adds custom connectors through an OAuth sign-in, and siar uses API keys, so connect from Claude Desktop or Claude Code for now.

Cursor

In ~/.cursor/mcp.json, or .cursor/mcp.json inside a project:

{
  "mcpServers": {
    "siar": {
      "url": "{{mcp_url}}",
      "headers": { "Authorization": "Bearer {{key}}" }
    }
  }
}

Codex

In ~/.codex/config.toml, with the key in an environment variable:

[mcp_servers.siar]
url = "{{mcp_url}}"
bearer_token_env_var = "SIAR_API_KEY"
export SIAR_API_KEY={{key}}

ChatGPT

ChatGPT connects to MCP servers through its own OAuth sign-in. siar authenticates agents with an API key, so ChatGPT cannot connect to it directly yet.

From OpenAI's side, use Codex (the CLI or the IDE extension): it reads the same key, and the Codex tab has the config.

Windsurf

In ~/.codeium/windsurf/mcp_config.json:

{
  "mcpServers": {
    "siar": {
      "serverUrl": "{{mcp_url}}",
      "headers": { "Authorization": "Bearer {{key}}" }
    }
  }
}
